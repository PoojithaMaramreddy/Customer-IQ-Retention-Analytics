# Customer IQ & Retention Analytics Platform

An end-to-end customer analytics project that transforms retail transaction data into customer intelligence, RFM-based segmentation, churn analysis, and interactive business dashboards.

---

## 📌 Project Overview

Businesses often have large amounts of transaction data but limited visibility into:

* Customer purchasing behavior
* Customer value
* Customer loyalty
* Customers at risk of churn
* Sales performance
* Geographic sales contribution

The **Customer IQ & Retention Analytics Platform** uses the **Online Retail II** dataset to analyze these areas and convert raw transaction data into customer and business insights.

---

## 🎯 Objectives

The project aims to:

* Understand and validate retail transaction data
* Clean and prepare the dataset for analysis
* Calculate customer-level RFM metrics
* Segment customers based on purchasing behavior
* Predict customer churn risk
* Analyze churn probability
* Identify at-risk customers
* Analyze sales performance over time
* Analyze geographic sales contribution
* Build an interactive Power BI dashboard

## 📊 Dataset

### Online Retail II

The project uses the **Online Retail II** dataset containing transaction-level records from an online retailer.

Major fields include:

| Column      | Description                      |
| ----------- | -------------------------------- |
| Invoice     | Invoice / transaction identifier |
| StockCode   | Product identifier               |
| Description | Product description              |
| Quantity    | Units purchased                  |
| InvoiceDate | Transaction date and time        |
| Price       | Unit price                       |
| Customer ID | Customer identifier              |
| Country     | Customer country                 |

**Dataset source:** Kaggle
**Original source:** UCI Machine Learning Repository

> The raw and processed datasets are intentionally excluded from Git tracking because of their size. The repository contains the project notebooks, documentation, and Power BI report.

## 🧹 Data Preparation

The project includes data understanding, cleaning, and validation.

Important checks include:

* Missing values
* Duplicate records
* Invalid quantities
* Invalid prices
* Missing customer identifiers
* Cancelled transactions
* Data type consistency
* Date validation
* Transaction values

### Feature Engineering

A transaction-level monetary value is calculated as:

```text
Total Amount = Quantity × Price
```

This value is used for sales analysis and customer-level monetary calculations.

---

# 👥 RFM Analysis

RFM analysis is used to understand customer purchasing behavior.

### Recency

Measures how recently a customer made a purchase.

### Frequency

Measures how frequently a customer purchases.

### Monetary

Measures the monetary value generated by the customer.

The resulting customer-level dataset contains:

```text
Customer ID
Recency
Frequency
Monetary
Segment
```

---

## 🧩 Customer Segmentation

Customers are grouped into five analytical segments:

| Segment             | Description                                                    |
| ------------------- | -------------------------------------------------------------- |
| Champions           | Highly engaged customers with strong purchasing behavior       |
| Loyal Customers     | Customers with consistent purchasing activity                  |
| Potential Loyalists | Customers showing potential for stronger loyalty               |
| At Risk             | Customers showing reduced recent engagement                    |
| Lost / Hibernating  | Customers with relatively weak or inactive purchasing behavior |

These classifications are project-specific analytical segments and are not universal industry definitions.

---

# 🤖 Churn Prediction

The project includes a customer-level churn prediction component.

The prediction output includes:

* Churn Probability
* Predicted Churn
* Actual Churn, where available

### Churn Probability

Represents the model's estimated probability that a customer may churn.

### Predicted Churn

A binary classification used to identify customers predicted as churn-risk customers.

---

## 📈 Churn Probability Bands

For dashboard analysis, churn probabilities are grouped into:

| Band    | Probability                   |
| ------- | ----------------------------- |
| 0–20%   | Low predicted risk            |
| 20–40%  | Relatively low predicted risk |
| 40–60%  | Moderate predicted risk       |
| 60–80%  | High predicted risk           |
| 80–100% | Very high predicted risk      |

These bands are dashboard categories created for this project.
